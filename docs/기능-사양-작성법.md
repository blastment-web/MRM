# 기능 살리기 — 지금 상태와 지시 방법

`AI 매니저 추천` · `AI Agent 등록` · `안내 챗봇` 세 가지를 어떻게 살리는지,
그리고 저에게 무엇을 알려주시면 되는지 정리했습니다.

---

## 0. 먼저 알아두실 것 — 백엔드가 있어야 하는 기능과 아닌 기능

`index.html` 은 화면 파일 하나입니다. 데이터를 **어디서 가져오느냐**에 따라 둘로 갈립니다.

| 구분 | 뜻 | 예 |
|---|---|---|
| **화면만으로 되는 것** | 이미 화면이 들고 있는 데이터(Agent 목록·좋아요·즐겨찾기)로 처리 | 검색, 필터, 추천 규칙, 모달 띄우기 |
| **서버가 필요한 것** | 값을 **저장**하거나 **다른 사람과 공유**해야 함 | 등록 신청 접수, 승인, 좋아요 집계, AI 답변 생성 |

서버가 필요한 기능은 같은 경로에 `api/…` 주소가 하나씩 있어야 합니다.
현재 저장소에는 **백엔드가 없습니다.** 다만 화면 쪽 호출 코드는 이미 다 들어가 있어서,
서버만 붙으면 바로 동작하도록 되어 있습니다.

---

## 1. AI Agent 등록 — **이미 살렸습니다**

버튼을 누르면 **등록 요청 모달**이 열립니다. 새로 만들지 않고 기존 화면을 연결했습니다.

- 입력: AI Agent 명 · 요청자 · 조직 · 설명 · 기능추가 선택 · HTML 파일 첨부
- 처리: `api/dash-request` 로 접수 → **1차 IT 검토** → **2차 적절성 검토** → 반영
- 현황 확인: 관리자 콘솔 `승인 관리` 탭, 또는 카테고리 화면의 `신청현황` 버튼

> 지금은 백엔드가 없어 **접수 단계에서 "서버에 연결할 수 없습니다"** 가 뜹니다.
> 화면 흐름은 전부 완성돼 있고, `api/dash-request` 하나만 붙이면 그대로 돕니다.

바꾸고 싶은 게 있으면 이 정도만 알려주세요.

- 입력칸을 더할지/뺄지 (예: "담당자 사번 칸 추가", "HTML 첨부는 빼기")
- 승인 단계를 2단계 그대로 둘지, 1단계로 줄일지
- 승인되면 어떻게 되는지 (자동으로 카테고리에 추가 / 관리자가 수동 등록)

## 2. 안내 챗봇 — **동작합니다. 예시 문구만 낡았던 것**

오른쪽 아래 말풍선 버튼입니다. **고장이 아니었습니다.**
열리고, 키워드를 넣으면 Agent 목록에서 찾아 카드로 보여줍니다.

문제는 예시 버튼이 예전 데이터(`에너지 사용량`·`알람`·`예산`)라 눌러도 **결과가 0건**이라
고장처럼 보였던 것입니다. 지금 데이터에 맞게 바꿔서 네 개 모두 결과가 나옵니다.

| 예시 버튼 | 결과 |
|---|---|
| 전체 목록 | 카테고리별 전체 |
| 수율 | 2건 |
| 원인분석 | 1건 |
| 회의록 | 1건 |
| 보고서 | 2건 |

### 더 똑똑하게 만들려면 — 두 갈래

**(A) 서버 없이 규칙만 개선** — 지금 방식은 단순 단어 포함 검사입니다.
동의어 사전(예: "불량"→"이슈·원인분석", "리포트"→"보고서")을 넣으면 체감이 크게 좋아집니다.
알려주실 것: **자주 쓰는 말 ↔ Agent 이름** 대응표. 엑셀 한 장이면 충분합니다.

**(B) 사내 LLM 연결** — 자연어로 묻고 답을 생성하려면 서버가 필요합니다.
알려주실 것: 사내에 쓸 수 있는 LLM 주소가 있는지, 있다면 **주소·인증 방식·요청/응답 형식**.
없으면 (A) 로 충분히 쓸 만합니다.

## 3. AI 매니저 추천 — **사양이 없어 그대로 뒀습니다**

지금은 "준비중입니다" 안내만 뜹니다. 무엇을 추천하는 기능인지 정해지면 만들 수 있습니다.
서버 없이 되는 범위가 꽤 넓습니다.

예를 들어 이런 식이면 **화면만으로** 됩니다.

> 버튼을 누르면 창이 열리고 → 내 조직과 하고 싶은 일(2~3개 질문)을 고르면
> → 조건에 맞는 Agent 를 좋아요 순으로 3개 추천

반대로 이런 건 서버가 필요합니다.

> 내가 지금까지 쓴 이력을 보고 추천 / 다른 사람들이 함께 쓴 Agent 를 추천

## 4. 지시 양식 — 이대로 채워서 주시면 됩니다

기능 하나에 대해 아래 8줄이면 충분합니다. 모르는 칸은 "알아서" 라고 적으셔도 됩니다.

```
[기능 이름]
1. 언제 눌리나   :
2. 무엇이 뜨나   :  (창이 뜬다 / 화면이 바뀐다 / 그 자리에서 결과가 나온다)
3. 사용자가 넣는 것:
4. 무엇을 기준으로 처리하나:
5. 결과로 보여줄 것:
6. 데이터는 어디서 :  (화면이 이미 아는 것 / 서버에서 받아야 함)
7. 누가 쓸 수 있나 :  (전체 / 로그인한 사람 / 관리자)
8. 결과가 없거나 실패하면:
```

### 기입 예시 — AI 매니저 추천

```
[AI 매니저 추천]
1. 언제 눌리나   : 대시보드 오른쪽 위 "AI 매니저 추천" 버튼
2. 무엇이 뜨나   : 가운데 창이 뜬다
3. 사용자가 넣는 것: 내 조직(5개 중 선택), 하고 싶은 일(문서정리/데이터분석/이슈대응 중 선택)
4. 무엇을 기준으로 처리하나: 고른 조직과 카테고리가 맞는 Agent 중 좋아요 많은 순
5. 결과로 보여줄 것: 카드 3개 (이름·설명·담당그룹·좋아요), 누르면 해당 Agent 로 이동
6. 데이터는 어디서 : 화면이 이미 아는 것
7. 누가 쓸 수 있나 : 전체
8. 결과가 없거나 실패하면: "조건에 맞는 Agent 가 아직 없습니다" 안내 + 전체 목록 보기 버튼
```

이 정도만 주시면 바로 만듭니다. 서버가 필요한 항목이 섞여 있으면
**어디까지 화면만으로 되고 어디부터 서버가 필요한지** 먼저 정리해서 알려드리겠습니다.
