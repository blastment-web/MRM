# MAPS V1

`index.html` 을 그대로 떠 둔 스냅샷입니다. 이후 작업으로 루트의 `index.html` 이 바뀌어도
이 폴더의 파일은 그대로 남습니다. 같은 시점에 git 태그 `MAPS-V1` 도 함께 찍혀 있습니다.

```bash
git show MAPS-V1:index.html > 어디든.html     # 태그에서 다시 꺼내기
```

## 이 버전에 담긴 것

| 화면 | 내용 |
|------|------|
| 대시보드 `#secHome` | 히어로(파티클 배경) · 현황 4종 · 조직 필터 + 카테고리 막대차트 · 공지사항 |
| TOP5 `#secTop5` | 좋아요 상위 5개 카드 |
| 카테고리별 AI Agent `#secPlatform` | 4개 카테고리 컬럼 · 검색 · 상태 범례 |
| 커뮤니티 `#secCommunity` | Q&A · 게시판 진입 (푸터까지 한 화면) |

레이아웃 규칙

- 좌우 여백 `--gut: clamp(20px, 6vw, 120px)` — 1366→82px, 1920→115px.
  챗봇 아이콘이 차지하는 오른쪽 76px 보다 항상 커서 카드와 겹치지 않는다.
- 네 화면 모두 `100svh - 네비` 안에 들어가며, 넘치면 JS `fitScreens()` 가
  `.tight` → `.tighter` 순으로 여백과 글자를 줄인다.
- 저사양·VDI 는 파티클 프레임 시간을 실측해 `body.lite` 로 자동 강등한다.

## 여는 방법

- **바로 확인**: 브라우저에서 `index.html` 을 열면 `FALLBACK` 데이터로 대시보드 ·
  TOP5 · 카테고리가 그려진다. 게시판 · Q&A · 공지는 백엔드가 없어 비어 있다.
- **화면 전체 확인**: 저장소 루트에서 `python3 tools/build_preview.py` 를 돌리면
  샘플 데이터가 들어간 미리보기와 **디자인 조정 패널**이 붙은 파일이 나온다.
- **운영**: 같은 경로에 `api/*` 백엔드와 `data/dashboards.json` 을 두면 그대로 동작한다.

## 디자인 조정 변수

`:root` 의 배율 변수로 주요 크기를 한 번에 조절할 수 있다(기본값 전부 `1`).

```
--gut          좌우 여백
--hero-scale   히어로 제목·태그라인·설명·버튼
--panel-scale  대시보드 3패널 (현황 숫자 · 차트 라벨 · 공지 글자)
--chip-scale   조직 필터 칩
--t5-scale     TOP5 카드 글자·버튼
--t5-h         TOP5 카드 높이
--card-scale   카테고리 카드 글자·버튼
```
