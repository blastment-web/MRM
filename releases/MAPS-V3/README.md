# MAPS V3

`index.html` 을 그대로 떠 둔 스냅샷입니다. 이후 작업으로 루트의 `index.html` 이 바뀌어도
이 폴더의 파일은 그대로 남습니다.

## 파일 두 개 중 어느 것을 열어야 하나

| 파일 | 용도 |
|------|------|
| `index.html` | **원본 스냅샷.** 실제 배포 대상. 한 글자도 건드리지 않는다. |
| `index.standalone.html` | **다른 PC · 다른 네트워크에 그냥 파일로 건네줄 때.** 로컬에서 켠 것과 화면·기능이 같아지도록 고친 사본. `python3 tools/build_standalone.py` 로 언제든 재생성된다. |

### standalone 사본이 고치는 것

원본을 사내가 아닌 곳에서 열면 히어로 애니메이션 · 스크롤 리빌 · 대시보드가 죽는다.
원인은 넷이고, 전부 코드에서 확인된 것이다.

- **P1 · 히어로 파티클이 한 번 스크롤하면 영영 안 돌아온다.** 화면 밖으로 나갈 때 `stop()` 은
  무조건 걸리는데, 되돌아올 때의 재시작만 `if(!REDUCED) start()` 로 막혀 있다.
  Windows `애니메이션 효과 표시` 끄기(회사 PC · VDI 기본값)에 걸리는 환경에서는
  히어로를 지나쳤다 올라오면 배경이 정지한 채로 남는다.
  원본 주석대로("정지가 아니라 가볍게") 재시작은 항상 하고, 부하는 이미 있는 LITE/TIER 가 낮춘다.
- **P2 · 감속모션에서 스크롤 리빌이 통째로 사라진다.** `.reveal{opacity:1;transition:none}` 이라
  등장 자체가 없다. 멀미의 원인인 이동(`translate`)은 계속 막고 페이드만 되살린다.
- **P3 · 백엔드가 없는 네트워크에서 대시보드가 영영 빈다.** `api/*` · `data/dashboards.json`
  요청이 프록시·캡티브포털을 만나면 실패하지 않고 매달린다. 그동안 `STATE` 가 비어 있어
  TOP5 · 막대차트 · STATS 카운트업이 안 그려지고 `boot()` 는 12초 만에 포기한다.
  GET 에만 2.5초 타임아웃을 걸어 폴백으로 즉시 넘어간다(POST 는 업로드가 있어 그대로 둔다).
- **P4 · 구형 Safari 에 부드러운 스크롤이 없다.** `scroll-behavior` 는 Safari 15.4 부터다.
  미지원이면 rAF 로 대신 굴린다.
- **P6 · 저부하 등급에서 배경 별자리가 사라진다.** `applyTier()` 가 점 개수(CAP·밀도)와
  연결 거리(LINK)를 **동시에** 깎는다. 연결선 수는 `점² × 거리²` 에 비례하므로 두 축을
  같이 줄이면 곱으로 무너진다 — 실측 1.634% → 0.111%(15배). TIER2 는 `LINK = 0` 이라
  연결선이 아예 0개다. 감속모션이면 무조건 TIER1 이므로, 회사 PC 에서는 점 몇 개만
  흩어진 화면이 된다. 부하를 줄이는 실제 지렛대는 프레임 간격과 `dpr=1` 이지 기하 밀도가
  아니므로, 프레임 스로틀은 그대로 두고 밀도·연결거리만 되살렸다. **TIER0 은 한 값도
  건드리지 않았다** — 일반 PC 의 모양은 지금 그대로다.

  | 등급 | 원본 | standalone | 캔버스 대비 그려진 픽셀 |
  |------|------|-----------|------------------------|
  | TIER0 (일반) | 78점 · LINK 150 | 그대로 | 1.63% → 1.78% (동일) |
  | TIER1 (감속모션) | 29점 · LINK 104 | 60점 · LINK 150 · 24fps | 0.111% → **1.041%** |
  | TIER2 (VDI·저사양) | 22점 · **LINK 0** | 44점 · LINK 132 · 18fps | 0.023% → **0.555%** |

  TIER1 의 CPU 비용은 TIER0 의 약 1/4, TIER2 는 약 1/10 로 여전히 가볍다
  (`점² × 프레임수` 기준).

- **P7 · 감속모션 설정 하나에 효과 절반이 꺼진다.** 원본은 OS 의 `prefers-reduced-motion` 을
  CSS 4곳 · JS 2곳에서 읽어 리빌 · 로고 펄스 · 스크롤 힌트 · 타일 트랜지션을 끄고 파티클을
  LITE 등급으로 내린다. Windows `애니메이션 효과 표시` 끄기는 회사 PC 기본값이라, 그 PC 로
  옮기는 순간 로컬에서 보던 화면과 딴판이 된다. standalone 은 **로컬과 같은 화면**이
  목적이므로 이 게이트를 전부 무력화한다. 저사양 보호는 실측 프레임 시간을 보는
  `degrade()` 가 계속 맡는다 — OS 설정이 아니라 실제 성능으로 판단한다.
  (원본 `index.html` 은 접근성 설정을 그대로 존중한다. 무력화는 사본 전용이다.)
- **P8 · 백엔드가 없어 자료공유 · 게시판 · Q&A 가 텅 빈다.** 로컬 미리보기가 넣어 주던 샘플을
  그대로 주입해 목록 · 상세 · 댓글 · 좋아요 · 정렬 · 검색까지 눌러 볼 수 있게 한다.
  데이터는 `tools/demo_data.py` 하나를 미리보기 빌드와 공유한다.
  공지는 건드리지 않는다 — script #3 의 `NOTICE_SAMPLE` 이 이미 8건을 갖고 있고
  `더보기 +` 토글이 그 총계를 기준으로 돌기 때문에, 덮으면 오히려 줄어든다.

## V2 에서 달라진 것

- **`AI 매니저 추천` 버튼을 챗봇 안으로 옮겼다** — 홈의 버튼은 "준비중" 토스트만 띄우는
  껍데기였다. 챗봇에서 **소속 → 업무 카테고리 → 해결하고 싶은 문제** 3단계를 고르면
  상위 3개를 추천하고 **추천 이유를 한 줄**로 붙인다.
  점수 = 조직 일치 3 + 카테고리 일치 3 + 이름 매칭 ×2 + 설명 매칭 ×1, 동점은 좋아요 순.
- **챗봇 예시를 현재 22개 데이터 기준으로 교체** — 입력창 안내문이 옛 데이터라 검색 결과가
  0건이었다. 첫 화면 칩도 5개 → 8개로 늘렸다.
- **챗봇 검색에 `org` 추가** — 조직명으로 검색해도 안 잡히던 것을 고쳤다.
- **공지 `더보기 +` 가 게시판으로 튀던 것을 목록 펼치기로** — 버그가 아니라 코드가 원래
  `showBoard()` 를 부르고 있었다. 이제 5줄 ↔ 전체를 토글하고 라벨도 `접기` 로 바뀐다.
- **공지 `글쓰기` 는 글쓰기 폼으로 직행** — 게시판 *목록* 이 뜨던 것을 고쳤다.
  관리자면 말머리가 `[공지]` 로 미리 잡히고 상단고정 체크까지 따라온다.
- **푸터 커뮤니티 Q&A · 게시판이 열린다** — `data-go` 가 없어 기존 위임에서 빠져 있었다.
- **게시판 · Q&A 화면에서 상단 네비와 푸터 링크가 살아난다** — `#mainView` 가 숨겨져 있으면
  `#secXxx` 앵커가 렌더 트리에 없어 조용히 실패했다. 홈으로 되돌린 뒤 스크롤한다.
- **톱니바퀴 = 설정** — 관리자 로그인이 아니라 설정 패널을 연다. hover 회전(35°)도 없앴다.
  글자 크기 · 화면 밀도 · 좋아요/즐겨찾기 초기화. 값은 브라우저에 저장돼 다시 열어도 유지된다.
  관리자 로그인은 헤더의 `관리자 로그인` 과 설정 패널 하단 두 곳에 남아 있다.
- **맨 위로 버튼** — 챗봇 아이콘 바로 위. 400px 이상 내리면 나타나고, 챗봇 창이 열리면 숨는다.
- **하단 고정 검색/채팅 바** — 화면 아래 가운데에 항상 떠 있다. 입력하고 Enter 를 치면
  챗봇 창이 열리며 그 질의로 답한다. 기능은 챗봇과 완전히 같다.

## 설계상 주의점 (다음 사람이 알아야 할 것)

- **신규 JS 는 script #3 의 IIFE 안에 있다.** `fitScreens` `toast` `refreshAll` `cols`
  `likeCount` `ORG_LIST` `LS_FAV` 가 전부 그 IIFE 의 지역 변수라 밖으로 빼면 전부 undefined 가 된다.
- **`#dockBar` 는 정적 마크업이다.** `fitScreens()` 가 첫 측정에서 바 높이를 실측해
  각 화면의 `avail` 에서 빼기 때문이다(`dockH()`). JS 로 만들면 첫 압축 등급이 한 박자 늦는다.
- **신규 요소에 `.reveal` 을 붙이면 안 된다.** 리빌 옵저버가 정적 수집 1회라 `opacity:0` 으로 굳는다.
- **`#gear` 와 `#ihNoticeMore` 는 `cloneNode` 로 갈아끼웠다.** script #1 의 익명 리스너를
  떼어낼 방법이 이것뿐이다. 두 id 모두 참조처가 한 곳씩이라 영향이 노드 하나로 닫힌다.
- **script #1 · #2 는 한 글자도 바뀌지 않았다** (각각 113,380자 / 3,117자 그대로).
- 하단 바 z-index 는 **45** — `.overlay`(50) 아래라 모달이 열리면 딤에 자동으로 가려진다.

  공지 샘플은 8건으로 늘려 `더보기 +` 동작을 눈으로 확인할 수 있게 했다(폴백 전용).
- `org` 22개 배정과 `likes` 값은 여전히 **가정치**다.
