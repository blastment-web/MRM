# MAPS V4-1

**V3 + 공통 수정사항 7건.** 히어로는 V3 의 별자리 파티클 네트워크를 그대로 둔다.

배경 영상 버전은 `releases/MAPS-V4-2/` 에 따로 있다. 두 버전 모두
`python3 tools/build_v4.py` 로 V3 에서 재생성된다 — V3 원본은 읽기만 한다.

| 파일 | 용도 |
|------|------|
| `index.html` | 원본 스냅샷. 실제 배포 대상. |
| `index.standalone.html` | 다른 PC 에 파일로 건넬 때. `python3 tools/build_standalone.py <입력> <출력>` 로 재생성. |

## V3 에서 달라진 것 (7건)

### 1) AI Agent 등록 요청 모달

- `1차 IT 검토 → 2차 적절성 검토 후 등록됩니다` 안내 문구 삭제
- 요청자 플레이스홀더 `이름 (비우면 '익명')` → `이름`
- **조직 → 기술그룹** 으로 라벨 변경, 플레이스홀더 `예 : 전극기술그룹`
- **팀 입력칸 신설**, 플레이스홀더 `예 : 믹싱공정기술팀`
- 설명 플레이스홀더 → `AI Agent에 대한 부연설명 기입`
- 기능추가 선택지를 카테고리 4종으로 교체 —
  `新공정/공법 개발` · `해외법인 양산 지원` · `제품 개발 대응` · `공통 및 루틴 업무`

새로 만든 `팀` 칸은 화면만 만들면 값이 서버로 안 넘어간다. 초기화 목록
(`["rqName",…]`)과 전송 payload(`JSON.stringify({… team …})`)에도 함께 연결했다.

### 2) 파우치형기술그룹 → 파우치/각형기술그룹

데이터·필터·차트 라벨 등 5곳 전부.

### 3) 태그라인

`Manufacturing Agent Platform & Shared-dashboard`
→ `Manufacturing **AI** agent Platform & Shared-dashboard`

강조 글자가 **M · A · P · S** 가 되도록 `AI` 의 `A` 에 accent 색과 굵기를 준다.
푸터 태그라인에는 원래 `.aria-ltr` 강조 규칙이 없어 흰 글자로만 나왔다 —
`.foot-tag .aria-ltr` 규칙을 추가해 히어로와 같은 강조를 준다.

### 4) "준비중" 앞 기호

`▪` → `●`. 사용 가능 · 접속 장애와 같은 크기·모양이 된다.
**두 곳이다**: 범례 칩(정적 마크업)과 카드 배지(`statusBadge()`). 카드 배지 쪽이
화면에서 훨씬 많이 보이므로 빠뜨리면 고친 티가 나지 않는다.

### 5) 카테고리별 AI Agent 화면 툴바

`대시보드` 라벨과 `추가요청` 버튼을 걷고, 대시보드 화면과 같은 얼굴의
`＋ AI Agent 등록` 버튼을 툴바 높이에 맞춰 넣었다.

- **id `dashReqBtn` 은 유지한다.** 히어로의 `#agentRegBtn` 이 이 버튼을
  `click()` 으로 위임하고 있어서, id 를 바꾸면 히어로 버튼이 조용히 죽는다.
- 스타일 선택자는 `.sys-btn.cat-reg-btn` 이다. 클래스 하나짜리로 두면 뒤쪽
  (661행)의 `.banner-btn,.sys-btn` 규칙에 밀려 그라디언트가 먹지 않는다.

### 6) 공지 표시 개수

`NOTICE_N` 5 → **4**. 더보기 노출·토글 기준도 같이 4 로 맞췄다.
한 화면에서 잘리지 않는다.

### 7) 공지는 [공지] 글만

`isNoticeOnly()` 로 `category === "공지"` 이거나 제목이 `[공지]` 로 시작하는
글만 남긴다. 폴백 샘플 8건 중 3건이 남는다.
