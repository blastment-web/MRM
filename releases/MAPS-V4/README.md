# MAPS V4

대시보드 화면의 히어로 배경을 **별자리 파티클 네트워크에서 배경 영상으로** 교체한 버전입니다.
그 외 화면·기능은 V3 과 같습니다.

## 파일 두 개 중 어느 것을 열어야 하나

| 파일 | 용도 |
|------|------|
| `index.html` | **원본 스냅샷.** 실제 배포 대상. |
| `index.standalone.html` | **다른 PC 에 파일로 건네줄 때.** 로컬에서 켠 것과 화면·기능이 같아지도록 고친 사본. `python3 tools/build_standalone.py` 로 재생성된다. |

## V3 에서 달라진 것

### 히어로 배경 = 영상 (대시보드 화면에만)

- `<canvas id="pxNet">` 와 `particleNet` IIFE(약 140줄)를 **완전히 제거**했다.
  `#pxNet` CSS 규칙도 함께 걷었다 — 남은 것은 주석의 이력 표기뿐이다.
- `#secHome` 안에 `<video id="heroVideo">` + `<div id="heroVeil">` 를 넣었다.
  붙는 위치가 V3 의 캔버스와 같으므로 **대시보드 화면에만** 적용되고 다른 섹션은 그대로다.
- `loop` 속성 대신 JS 로 **3~8초 구간만** 반복한다. `timeupdate` 는 초당 4~5회라 종료
  지점을 살짝 넘길 수 있어, 되돌린 뒤 `play()` 를 다시 불러 루프 순간 멈추는 것을 막는다.
- 원 소스: `https://www.lgensol.com/inc/video/video_main01.mp4#t=3,8`

### 원본 템플릿에서 의도적으로 달리 한 것

| 항목 | 제시된 템플릿 | V4 | 이유 |
|------|--------------|-----|------|
| 배치 | `100vw × 100vh` 고정 · `z-index:-2` | `#secHome` 안에서 `inset:0` · `z-index:0` | `-2` 는 페이지 배경 뒤로 숨어 보이지 않는다. V3 캔버스가 쓰던 자리를 그대로 물려받는다. |
| 크기 맞춤 | `min-width/height` + `translate(-50%,-50%)` | `inset:0` + `object-fit:cover` | 결과는 같고 리플로우가 없다. |
| 딤 | 단색 `rgba(0,0,0,.4)` | 위 .34 → 아래 .88 세로 그라디언트 | 아래쪽에 현황·차트·공지 패널이 얹힌다. 단색이면 패널 글자가 영상에 묻힌다. |
| 재생 제어 | 항상 재생 | 화면 밖 · 탭 비활성이면 일시정지 | 배경 영상이 계속 디코딩되면 스크롤이 무거워진다(V3 에서 캔버스를 세우던 것과 같은 이유). |
| 실패 처리 | 없음 | `error` · 8초 무응답이면 스스로 숨김 | 사내망에서 외부 영상이 막히면 깨진 영역 대신 기존 그라디언트만 남는다. |

### 패널 대비 보정

`.dash-panel` 배경은 `rgba(255,255,255,.045)` 수준의 반투명 그라디언트뿐이라, 어두운
페이지 배경을 전제로 만들어져 있었다. 배경이 밝은 영상으로 바뀌자 패널 너머로 영상이
비쳐 글자가 읽히지 않았다. `#secHome .dash-panel` 에만 불투명 판(`rgba(9,13,24,.88)`)을
한 겹 깔았다. `backdrop-filter` 는 쓰지 않는다 — 스크롤 중 합성 비용이 크다.

## 검증 (Chromium)

영상 URL 은 이 저장소를 빌드한 환경의 네트워크 정책에서 차단되어 있어(`connect_rejected`),
**실제 lgensol.com 영상의 재생 여부는 확인하지 못했다.** 동작 검증은 같은 조건의
로컬 테스트 영상으로 했고, 실제 URL 로는 차단 시 폴백만 확인했다.

## 알아 둘 것

- **영상은 외부 주소를 그대로 참조한다.** 파일 안에 담겨 있지 않으므로, 인터넷이
  없거나 `lgensol.com` 이 막힌 망에서는 재생되지 않고 폴백 배경이 나온다.
  사내 배포 시에는 영상을 사내 서버에 올리고 `<source src>` 를 그 주소로 바꾸는 편이 안전하다.
- 남의 사이트 자산을 직접 링크하는 방식이라, 상대 서버가 경로를 바꾸면 조용히 폴백으로 떨어진다.
- 감속모션(Windows `애니메이션 효과 표시` 끄기)에서 `index.html` 은 영상을 첫 프레임에
  세워 둔다. `index.standalone.html` 은 로컬과 같은 화면이 목적이라 그대로 재생한다.
