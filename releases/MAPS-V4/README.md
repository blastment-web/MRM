# MAPS V4

대시보드 화면의 히어로 배경을 **별자리 파티클 네트워크에서 배경 영상으로** 교체한 버전입니다.
그 외 화면·기능은 V3 과 같습니다.

## 파일 두 개 중 어느 것을 열어야 하나

| 파일 | 용도 |
|------|------|
| `index.html` | **원본 스냅샷.** 실제 배포 대상. |
| `index.standalone.html` | **다른 PC 에 파일로 건네줄 때.** 로컬에서 켠 것과 화면·기능이 같아지도록 고친 사본. `python3 tools/build_standalone.py` 로 재생성된다. |

## V3 에서 달라진 것

### 히어로 배경 = 영상 (대시보드 화면에만)

- `<canvas id="pxNet">` 와 `particleNet` IIFE(약 140줄)를 **완전히 제거**했다.
  `#pxNet` CSS 규칙도 함께 걷었다 — 남은 것은 주석의 이력 표기뿐이다.
- `#secHome` 안에 `<video id="heroVideo">` + `<div id="heroVeil">` 를 넣었다.
  붙는 위치가 V3 의 캔버스와 같으므로 **대시보드 화면에만** 적용되고 다른 섹션은 그대로다.
- `loop` 속성 대신 JS 로 **3~8초 구간만** 반복한다. `timeupdate` 는 초당 4~5회라 종료
  지점을 살짝 넘길 수 있어, 되돌린 뒤 `play()` 를 다시 불러 루프 순간 멈추는 것을 막는다.
- 원 소스: `https://www.lgensol.com/inc/video/video_main01.mp4#t=3,8`

### 원본 템플릿에서 의도적으로 달리 한 것

| 항목 | 제시된 템플릿 | V4 | 이유 |
|------|--------------|-----|------|
| 배치 | `100vw × 100vh` 고정 · `z-index:-2` | `#secHome` 안 · `top:var(--nav-h)` · `z-index:0` | `-2` 는 페이지 배경 뒤로 숨어 보이지 않는다. 헤더는 `position:fixed` 에 최상단 배경이 `transparent` 라, `top:0` 이면 메뉴 글자가 영상 위에 얹힌다. |
| 크기 맞춤 | `min-width/height` + `translate(-50%,-50%)` | `height:calc(100% - var(--nav-h))` + `object-fit:cover` | `<video>` 는 대체 요소라 `height:auto` 면 `top/bottom` 이 아니라 **영상의 고유 종횡비**로 높이를 잡아 섹션 아래가 빈다. 실제로 그 버그를 겪고 `calc` 로 못 박았다. |
| 노출 범위 | 화면 전체 | 히어로 밴드까지만 (`mask-image` 로 아래 페이드아웃) | 3패널이 영상 위에 얹히면 가독성이 무너진다. 밴드로 한정하면 패널이 원래 페이지 배경 위에 놓여 **불투명 판 자체가 불필요**해진다. |
| 딤 | 단색 `rgba(0,0,0,.4)` | 위 .30 → 아래 .55 세로 그라디언트 | 마스크로 영상이 패널 전에 사라지므로 아래를 무겁게 덮을 이유가 없다. |
| 재생 제어 | 항상 재생 | 화면 밖 · 탭 비활성이면 일시정지 | 배경 영상이 계속 디코딩되면 스크롤이 무거워진다(V3 에서 캔버스를 세우던 것과 같은 이유). |
| 실패 처리 | 없음 | `error` · 8초 무응답이면 영상·딤 모두 숨김 | 사내망에서 외부 영상이 막히면 깨진 영역 대신 기존 그라디언트만 남는다. |

### 마스크 정지점 — 폭에 따라 3구간

페이드는 **CTA 버튼이 끝난 뒤 ~ 3패널이 시작하기 전**의 빈 구간에서 끝나야 한다.
그 위치가 레이아웃 전환에 따라 갈리므로 폭별로 정지점을 달리 잡았다
(영상 높이 대비, Chromium 22개 뷰포트 실측).

| 폭 | CTA 끝 | 패널 상단 | 페이드 |
|----|--------|----------|--------|
| >1200px | 30~36% | 45~53% | 36% ~ 44% |
| 901~1200px | 28~31% | 42~49% | 32% ~ 41% |
| ≤900px | 20~25% | 33~40% | 26% ~ 32% |

900px 이하에서 `--nav-h` 가 60 으로 줄며 비율이 한 번 더 바뀐다.

### 문구 뒤 어둠막 제거

`#secHome .hero::before` 는 "파티클 위 글씨가 묻히지 않도록" 넣은 radial 스크림이었다.
거의 검정이던 별자리 배경에서는 보이지 않았지만, 밝은 영상 위에서는 **문구~CTA 영역을
덮는 큰 어두운 타원**으로 드러났다. 이 블록을 걷고 글자 자체에 그림자를 줬다.

- 제목: `filter: drop-shadow(...)` — `text-shadow` 가 아니다. 제목 안
  `<span class="grad">` 이 `background-clip:text` + `-webkit-text-fill-color:transparent`
  라서 `text-shadow` 를 주면 투명한 글자 속으로 그림자가 비쳐 지저분해진다.
  `drop-shadow` 는 렌더 결과의 알파를 따르므로 그라디언트 글자에서도 정상 동작한다.
- 그 외 단색 문구(eyebrow · 태그라인 · 부제): `text-shadow` (더 가볍다)

### 패널

**V3 상태 그대로 둔다.** 영상이 마스크로 패널 위에서 끝나므로 뒤에 비칠 것이 없어,
불투명 판을 깔 이유가 사라졌다.

## 알아 둘 것

- **영상은 외부 주소를 그대로 참조한다.** 파일 안에 담겨 있지 않으므로, 인터넷이
  없거나 `lgensol.com` 이 막힌 망에서는 재생되지 않고 폴백 배경이 나온다.
  사내 배포 시에는 영상을 사내 서버에 올리고 `<source src>` 를 그 주소로 바꾸는 편이 안전하다.
- 남의 사이트 자산을 직접 링크하는 방식이라, 상대 서버가 경로를 바꾸면 조용히 폴백으로 떨어진다.
- 감속모션(Windows `애니메이션 효과 표시` 끄기)에서 `index.html` 은 영상을 첫 프레임에
  세워 둔다. `index.standalone.html` 은 로컬과 같은 화면이 목적이라 그대로 재생한다.
